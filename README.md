# Info
This theme was developed from the tokyo nights theme, and altered for a new deeper / darker feel with a slight cyberpink feel to it.

There are two files in this repo, the `melbourne-nights.xml` file and a bash installer script

# How to use
## Gedit / GNOME text editor
To use the theme in GNOME text editor on Ubuntu >= 22.04 you can simply download the .xml file and load it in the profiles section of the settings, this works on ubuntu 22.04 and POP_OS! 22.04.

### Ubuntu 24.04
You will need to copy the file to `/usr/share/gtksourceview-6/styles/`, close and reopen gedit and the theme will show up in the settings now.

## GNOME Terminal
To use the theme in GNOME terminal on ubuntu >= 22.04 you can simply download the `.sh` installer file, run `chmod +x installer.sh` then excecute the installer, after it is done, right click anywhere on the terminal and select the new theme and make it default. Then close and reopen your terminal.
